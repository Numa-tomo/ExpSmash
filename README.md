# Exp Smash (Prototype)
### Overview
Collect as many items as possible before time runs out.
After exploration, a challenge event begins where your collected power determines your performance.
### Features
- Third-person character control
- Random item spawning
- Timer-based exploration
- Event stage transition
- Object pooling
- Cinemachine camera
